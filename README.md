# 📚 DSA Lecture Notes

A growing collection of **Data Structures & Algorithms** lecture notes, hand-curated and updated daily.  
Whether you're prepping for placements, competitive programming, or just learning — this repo is for you.

---

## 🗂️ What's Inside

Notes are organized topic-wise for easy navigation:

```
📁 Arrays
📁 Linked Lists
📁 Stacks & Queues
📁 Trees & Binary Search Trees
📁 Graphs
📁 Recursion & Backtracking
📁 Sorting & Searching
📁 Dynamic Programming
📁 Greedy Algorithms
📁 Hashing
```

> Structure will keep evolving as new topics are added.

---

## ✍️ Format

Each note typically includes:

- 📌 **Concept explanation** — simple, to-the-point theory
- 🔢 **Time & Space Complexity** — Big-O analysis
- 💻 **Code snippets** — in C++
- 🧩 **LeetCode-style problems** mapped to the topic
- 🧠 **Key intuitions & patterns** to remember
